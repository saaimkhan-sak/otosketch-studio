# Clinical Scope

MVP procedure pack:

- Tympanoplasty
- Tympanoplasty with ossiculoplasty
- Ossiculoplasty

Supported anatomy:

- Tympanic membrane
- Malleus
- Incus
- Incudostapedial joint
- Stapes

Supported repairs:

- Temporalis fascia graft
- Cartilage graft
- OtoMimix / bone cement bridge
- PORP
- TORP
- No reconstruction documented

Out of scope for the MVP:

- Cholesteatoma mapping
- Mastoidectomy cavity diagrams
- Cochlear implant workflows
- Sinus, airway, and oncology procedures
- Real EHR integration
- Real patient data import
- Prognosis or treatment recommendations
